# GIFinder

Aplicación frontend desarrollada con Vite y TypeScript para consultar,
buscar y visualizar contenido multimedia mediante la API de Giphy.

## Tecnologías- HTML- CSS- TypeScript- Vite- PNPM

## Requisitos- Node.js LTS- PNPM

## Instalación

```bash
pnpm install
```

## Ejecución

```bash
pnpm dev
```

## Compilación

```bash
pnpm build
```

## Autor

Urbina Gutiérrez Angel

## Funcionalidades actuales- Representación tipada de GIFs.- Galería generada desde un arreglo local.- Búsqueda por título, autor, etiqueta y descripción.- Manejo del caso sin resultados.
